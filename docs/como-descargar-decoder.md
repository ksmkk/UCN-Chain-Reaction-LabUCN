# Cómo usar el decoder en TryHackMe

**Existe un único decoder para esta clase:** [abrir decoder para terminal](../herramientas/decoder-terminal.md).

1. En la máquina Ubuntu, entra a la carpeta del proyecto que identificaste durante la investigación.
2. Abre el enlace y copia **todo el bloque**, desde `python3 - <<'PY'` hasta la última línea `PY`.
3. Pégalo directamente en la terminal. No necesitas crear archivos ni instalar dependencias.
4. Interpreta las cadenas decodificadas para responder las preguntas 5–7.

La herramienta únicamente lee el JavaScript como texto; no lo ejecuta ni establece conexiones externas.
